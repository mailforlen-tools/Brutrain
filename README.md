# Brutrain (concept)

Single-page train planner and live board for the 34 stations in the Brussels-Capital Region plus Brussels Airport.
Languages: NL, FR, EN, DE, ES.

Status: **concept / draft**. The page contains a frozen demo snapshot (28 Aug 2026) and is not meant for real travel advice.

Open `index.html` in a browser.

Sources: [iRail](https://docs.irail.be/), Infrabel open data, NMBS/SNCB GTFS-RT.
